# Quantized dots GPU warmup fix · 0.1.0-rc.4

The real parsing worker now skips the native server's fixed-size dummy vision
warmup. On the tested GTX 1660 Ti 6 GB, rc.3 exhausted VRAM while reserving a
3,645.66 MiB dummy workspace; disabling that step lets the real synthetic page
complete. This keeps Q4_K_M language / Q8_0 projector weights, actual page pixel
limits and full GPU offload unchanged. It does not guarantee arbitrary pages fit.

The synthetic GPU check covers preparation, text/table extraction, canonical
exports, review HTML and server teardown, with no cloud calls. It is a runtime
regression probe, separate from OCR-quality evaluation. Earlier rc.3 failure
evidence is retained; CPU-hosted checks are not credited as GPU inference.

The default remains quantized dots for the 6 GB laptop. Original BF16 dots scored
best on selected handwritten mathematics (32/37 vs Q4 29/37), with 8.53 GiB peak
PyTorch allocation on Colab T4; this is not total VRAM or a universal ranking.
Optional visual descriptions use Gemma through Ollama Cloud. Weights and secrets
are not bundled. The public four-profile demo remains version 4.1.

The exact public image also passed the synthetic GPU worker test on GTX 1660 Ti.
Two preceding attempts failed to allocate vision weights under Windows host-memory
pressure (652 MiB available RAM); the unchanged image succeeded after releasing
reclaimable WSL file caches. These retries remain in the validation record.
