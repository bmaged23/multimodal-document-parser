# GPU document-parsing pipeline — release candidate 2

The parsing runtime is available as a public Linux amd64 image:

```bash
docker pull bmaged23/multimodal-document-parser:0.1.0-rc.2
```

It includes separate preparation/parsing APIs and workers, PDF rendering, DOCX
conversion, PaddleOCR-VL-1.6 GPU inference, canonical JSON/Markdown/HTML exports,
and the Ollama Cloud client for optional chart/image descriptions. Gemma executes
remotely; provide your API key at runtime. The separate dots.mocr comparison
server, model weights, private inputs and the full RAG stack are not bundled.

The image was built and published by
[GitHub Actions](https://github.com/bmaged23/multimodal-document-parser/actions/runs/41424942053).
Source/browser CI, container runtime checks and anonymous registry access passed.
SPDX SBOM and SLSA build provenance accompany the image. Its source revision is
`5d3c1ba9ccf00917307e0616292632b9e232f1e3`.

Immutable image index:
`sha256:fbd8e78741c933e04de58ab5648f55b3846cad65fc73290ba7ac8a35eb580c34`.

Hosted runners do not provide an NVIDIA GPU. Actual CUDA tensor validation covers
the earlier local `0.1.0-rc.1` image; no fresh OCR corpus run or cloud call was made
for this release. Legacy `.doc` and encrypted documents are unsupported, and
extraction quality varies with layout, image quality and handwriting.

no live inference and is not the complete local evaluation archive. GitHub's
source archives refer to the exact image source revision; current presentation
guides and the demo are linked separately above.
